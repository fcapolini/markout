The two tags

<std-router> holds a <std-route> per screen and reads the query. Put a router inside a route and it owns the next segment of the path.

A route publishes ::selected, which is what every nav on these two pages reads to mark its active link.

The two questions an address can fail

An address can name no screen — a bare / — which is the front door, and resolves to ::defaultPage. Or it can name one that does not exist, which is the 404, and resolves to ::fallback.

They are separate parameters so that a visible “no such page” does not end up answering the front door. Both default to index.
