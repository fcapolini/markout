Two kinds of navigation

The pathname decides where a round trip is unavoidable. The query string decides everything inside one.

${servedAt}

A :server- value, frozen into the markup. It can only change if a document was fetched.

${$url?.search || '(nothing)'}

Sent to the server, unlike a #fragment — so the response is already this screen.

One file, three screens

Every link above is the same file with a different query. The server renders the screen the query names, so this page is correct in the response before any JavaScript runs — which is what makes these addresses worth pasting into a chat window.

Watch the stamp while you move between them. It does not change, because nothing was fetched.

A section with screens of its own

This route holds a router of its own, so the address grows a second segment: ?guide/install. Neither level was told its own depth — each asks the nearest router above it, through $outer.

Introduction

The sidebar beside this text belongs to the enclosing route. It is rendered once and left alone while these panels change, which is the thing nesting is for.

Install

The address now reads ?guide/install. Reload the page on it: the stamp changes, because that is a round trip — and this exact panel comes back, because the server can read the query.

What the address carries besides the page

The query has two parts. Its leading segment is the page path, and anything carrying = is a parameter — so ?params&sort=name is this screen with a parameter beside it, and ?sort=name alone names no screen at all.

What happens without the Navigation API

Every link on this page is an ordinary <a href>. A browser that can intercept keeps the document and swaps the screen; one that cannot fetches the same file with a different query and arrives at the same screen. The markup is identical either way — the fallback is not a code path, it is what happens when nothing intercepts.

An address naming no screen lands on ::defaultPage, so ?utm_source=nl on a link to this page shows the overview rather than a blank frame.

The reference page is a different file, so opening it is a round trip by design — and the stamp on the other side will say so. That is the choice the pathname makes: not a limitation to route around, but where you decided a fresh document was the right answer.
