Bootstrap + Markout

What if you could add application logic directly to your Bootstrap page?

Build interactive Bootstrap applications without bringing in a frontend framework.

Markout makes HTML modular, reactive, and isomorphic — so you can start with ordinary Bootstrap markup and add application logic directly where it belongs: in the page.

Bootstrap Kit

Use the Bootstrap components you already know

Markout's Bootstrap Kit provides reusable Bootstrap components as ordinary Markout fragments.

Buttons, modals, dropdowns, tabs, accordions, cards, forms, alerts — use them as building blocks for your application.

And because they're Markout fragments, you can open them, understand them, customize them, and extend them.

They're yours. No black boxes. No component registration ceremony. No special extension API.

No framework required

Markout doesn't try to replace HTML with a component framework.

It asks a different question:

What would web development look like if HTML itself was modular and reactive?

The answer is a small reactive runtime sitting underneath your markup — not an application framework sitting above it.

Isomorphic by design

The same application on the server and in the browser

Markout is isomorphic by design.

The same Markout application can run on the server to produce HTML and in the browser to make that HTML reactive.

No separate server template. No separate client application. No framework-specific hydration model to understand.

It's the same application.

Small by design

A tiny runtime for a much more expressive HTML

Markout's reactive runtime is small by design.

The goal isn't to build the biggest framework. It's to put the smallest possible amount of machinery underneath a much more expressive form of HTML.
